
# 🏥 Hospital Emergency Room Dashboard

A dynamic and interactive **Hospital Emergency Room Dashboard** built to analyze patient flow, waiting times, satisfaction scores, and department referrals. This project provides meaningful insights to help improve hospital operations and patient care efficiency.

---

## 📊 Project Overview

This dashboard presents a **monthly report** of emergency room activity, including:

* Total number of patients
* Average wait time
* Patient satisfaction score
* Admission status (Admitted vs Not Admitted)
* Patient attendance status (On-time vs Delay)
* Gender distribution
* Age group analysis
* Department-wise patient referrals

---

## 🚀 Features

* 📅 **Month-wise filtering** (Jan–Dec)
* 📈 **KPI Cards** for quick insights:

  * Total Patients
  * Average Wait Time
  * Satisfaction Score
* 🧑‍🤝‍🧑 **Demographic Analysis**:

  * Gender distribution
  * Age group segmentation
* 🏥 **Department Referral Tracking**
* ⏱️ **Patient Attendance Monitoring**
* 📊 Clean and intuitive visual design for decision-making

## 📌 Insights Derived

* Balanced admission rate (~48% admitted)
* Majority of patients are handled without referral ("None" category)
* Gender distribution is nearly equal
* Most patients fall within mid-age groups (20–60)
* Opportunities to reduce delays and improve satisfaction
